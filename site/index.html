ployz

Rust reconstruction of Uncloud preserving its deliberate architecture and limitations

Quick Install

Install via curl

curl -fsSL https://ployz.sh/install.sh | sh

Install via Homebrew

brew install getployz/ployz/ployz

Manual Download

Download the installation script:

curl -fsSL https://ployz.sh/install.sh -o install.sh chmod +x install.sh ./install.sh

# CLI freeze

`cli-freeze/` is the committed command-shape oracle for `ployz/tests/cli_shape.rs`.

Add or remove a page when the clap tree changes. `CLI_DEVIATIONS.md` lists Ployz-owned flags and commands that the freeze pages do not describe.

`product-paths.tsv` is the product-path menu for test rungs. `scripts/check-product-paths.sh` verifies locators.

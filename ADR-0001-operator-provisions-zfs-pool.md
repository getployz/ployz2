# Operator provisions the Machine ZFS Pool

There is no cluster zpool. `CreateZfsPool` is a Machine RPC (same targeting as `volume create`: `--machine` required when more than one Machine exists). An operator creates a Machine ZFS Pool (`--size 100G`, `--size 80%` of **that** Machine’s available backing-FS space resolved once, or `--from` an imported zpool on that Machine). Overcommit on that pool defaults to 120% (`allocatable = pool_bytes × 1.2`). List/deploy observe fan out; they do not create a cluster resource. `machine init` is out of scope. Hidden auto-create on first `x-zfs` would pick a disk budget the operator never approved, and send/recv is out of scope so the pool stays machine-local on purpose.
